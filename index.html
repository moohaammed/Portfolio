Projet phare — formation
Infrastructure virtualisée multi-hyperviseur — Domaine tunisair.lab
mohamed.kadi@tunisair-lab: ~/infrastructure
Deux hyperviseurs, un seul stockage, un seul annuaire.

Conception et dépannage d'une infrastructure d'entreprise associant VMware vSphere et CNware/ZStack, reliés au même stockage SAN Dell PowerVault en iSCSI, avec un Active Directory centralisé et une couche d'orchestration Ansible capable de piloter du Linux, du Windows et du VMware depuis un seul point de contrôle.

Déroulement, phase par phase
  1. Préparation des serveurs physiques
    Formatage, RAID 5 local (PERC H310), installation des hyperviseurs ESXi et CNware/NexaVM.
  2. Diagnostic de la baie de stockage
    Détection d'un contrôleur RAID retiré/en panne via le Recovery Guru — root cause d'une absence de connexion iSCSI que le simple ping ne révélait pas.
  3. Reconnexion iSCSI multi-sous-réseaux
    Dual-homing réseau sur chaque hôte pour joindre le contrôleur survivant, puis agrandissement de LUN sous-dimensionnés.
  4. Stockage partagé & clusters
    Datastore VMFS partagé côté vCenter, stockage Shared Block côté CNware — les deux nœuds de chaque cluster voient le même disque.
  5. Active Directory
    Déploiement d'un contrôleur de domaine (AD DS, DNS, DHCP) sur le domaine tunisair.lab.
  6. Connectivité inter-clusters
    Résolution d'un cloisonnement réseau entre les deux clusters (sous-réseaux séparés sur un switch L2 sans routage).
  7. Orchestration Ansible
    Nœud de contrôle déployé et alimenté hors-ligne, playbooks Linux + Windows (WinRM) + VMware (API REST vCenter).
